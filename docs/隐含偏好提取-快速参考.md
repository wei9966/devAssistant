# 隐含偏好提取 - 快速参考卡片

## 一分钟了解

这个功能让 AI 助手能够从你的日常对话中**自动学习和记住**你的工作习惯。

## 支持的识别类型

### ⏰ 时间偏好
```
你说："我一般下午效率高"
AI：（自动记住）下午是你的高效时段
```

### 🍅 工作模式
```
你说："我习惯用番茄钟，一个番茄钟25分钟"
AI：（自动记住）你的番茄钟时长是25分钟
```

### ⚡ 优先级表达
```
你说："这个很重要，必须今天完成"
AI：（自动设置）高优先级 + 紧急
```

### 📁 项目关联
```
你说："这是DevAssistant项目的新功能"
AI：（自动关联）任务 → DevAssistant项目
```

## 如何使用

### 完全自动，无需额外操作！

只需像平时一样和 AI 对话，它会自动：
1. ✅ 识别你的习惯和偏好
2. ✅ 保存到本地数据库
3. ✅ 在后续对话中应用这些偏好

## 示例对话

### 场景 1：学习工作时间
```
第1天
你："我一般下午效率高，适合处理复杂任务"
AI："明白了！" [自动保存：时间偏好=下午]

第7天
你："帮我安排今天的任务"
AI："根据你的习惯，建议把复杂任务安排在下午..." [自动应用偏好]
```

### 场景 2：记住番茄钟习惯
```
第1次
你："我习惯用番茄钟，一个番茄钟25分钟"
AI："好的，已记录你的番茄钟偏好" [自动保存：时长=25分钟]

之后
你："启动番茄钟"
AI："为你启动25分钟的番茄钟..." [自动使用保存的时长]
```

### 场景 3：理解优先级
```
你："创建任务：写周报，这个很重要"
AI："已创建高优先级任务「写周报」" [自动识别优先级]

你："创建任务：整理文档，不着急"
AI："已创建低优先级任务「整理文档」" [自动识别优先级]
```

## 触发关键词

### 时间偏好
- "我一般/习惯/通常/喜欢 + 时间段"
- "时间段 + 效率高/适合"

### 工作模式
- "我习惯/喜欢用 + 番茄钟/分块/专注"
- "一个番茄钟 + 数字 + 分钟"

### 优先级
- **高**："很重要/必须/紧急"
- **低**："不着急/不急/慢慢来"
- **紧急**："今天必须/必须今天"

### 项目关联
- "这是XXX项目的"
- "XXX项目相关"
- "和上次那个任务有关"

## 重要性评分

| 评分 | 说明 | 示例 |
|------|------|------|
| 9-10 | 紧急必须 | "必须今天完成" |
| 7-8 | 明确习惯 | "我习惯..." |
| 5-6 | 隐含偏好 | "效率高" |
| 3-4 | 临时表达 | "这次..." |

评分越高，后续对话中权重越大。

## 查看保存的偏好

### 方法 1：通过数据库查看
```sql
SELECT * FROM context_memory
WHERE context_type = 'preference'
ORDER BY importance DESC;
```

### 方法 2：通过日志查看
启动应用时查看日志：
```
[Context Memory] 提取到时间偏好: 下午 (重要性: 8)
[AI Chat] 💾 保存上下文记忆: time_preference
```

## 清除偏好

如果需要删除保存的偏好：
```sql
DELETE FROM context_memory
WHERE context_type = 'preference';
```

或者在应用设置中清除所有上下文记忆。

## 隐私说明

✅ **不上传云端**：数据不会发送到外部服务器
✅ **用户可控**：随时可以查看和删除

## 常见问题

### Q: 会自动学习所有对话内容吗？
A: 不会。只识别特定的模式（时间偏好、工作模式、优先级、项目关联）。

### Q: 可以修改已保存的偏好吗？
A: 可以。新的表达会更新已有偏好，权重更高的记录优先级更高。

### Q: 识别错了怎么办？
A: 可以通过数据库手动删除错误的记录，或者在对话中明确纠正。

### Q: 影响性能吗？
A: 几乎无影响。正则匹配耗时 < 1ms，使用静态编译的模式。
