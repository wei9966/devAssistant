## 1. 项目概述

DevAssistant 是一款面向开发者的桌面效率工具，采用 Tauri 框架开发，结合 Vue 3 前端和 Rust 后端，提供任务管理、番茄钟、SQL历史、屏幕上下文采集、应用启动器等多种功能。

### 1.1 核心特性

| 功能模块 | 描述 |
|---------|------|
| **任务管理** | 完整的任务生命周期管理，支持四象限优先级矩阵 |
| **番茄钟** | 专注计时器 + AI 中断分析和恢复建议 |
| **SQL历史** | SQL执行历史 + AI自动分类 + 模板识别 |
| **屏幕上下文** | 自动截图采集、活动追踪、工作时间线 |
| **应用启动器** | 快速启动应用，支持拼音搜索和工作流 |
| **工作日志** | AI辅助生成日报、周报 |
| **数据统计** | 热力图、趋势分析、应用使用统计 |
| **剪贴板历史** | 剪贴板内容记录和管理 |

### 1.2 多窗口架构

| 窗口 | 用途 | 尺寸 | 特性 |
|------|------|------|------|

## 3. 前后端通信机制

### 3.1 Tauri Invoke 模式

前端通过 `@tauri-apps/api/core` 的 `invoke` 函数调用后端 Rust 命令：

```typescript
import { invoke } from '@tauri-apps/api/core'

// 基本调用模式
const result = await invoke<ReturnType>('command_name', {
  param1: value1,
  param2: value2
})
```

### 3.2 参数传递规范

| 规范 | 说明 |
|------|------|
| 传递方式 | 对象方式 `{ key: value }` |
| 命名转换 | 前端驼峰 → 后端snake_case (自动转换) |
| 可选参数 | 使用 `param \|\| null` 或 `param?` |
| 返回值 | 异步 `Promise<T>` |
| 类型安全 | 支持泛型 `invoke<T>()` |

```
创建会话 → 设置专注目标
    ↓
开始计时 → 专注中
    ↓          ↓
暂停 ←→ 继续  中断 → AI分析中断原因
    ↓
完成会话 → 记录进度 → AI生成复盘
```

### 7.3 屏幕上下文采集流程

```

    ↓
屏幕截图 → 哈希计算
    ↓
相似度比对 → 去重
    ↓
VLM分析 → 提取内容
    ↓
存储上下文 → 生成时间线
```
