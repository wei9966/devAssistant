## 规划中的工具

### 一、开发常用工具

#### 1. JSON 格式化器
- **功能**: 格式化、压缩、校验 JSON
- **特性**:
  - JSON 格式化（美化）
  - JSON 压缩（移除空格换行）
  - JSON 语法校验，显示错误位置
  - JSON ↔ JavaScript 对象转换
  - 支持大文件处理
- **优先级**: ⭐⭐⭐⭐⭐

#### 2. 正则表达式测试器
- **功能**: 实时测试正则表达式
- **特性**:
  - 实时匹配高亮
  - 显示捕获组
  - 常用正则模板（邮箱、手机号、URL 等）
  - 支持多行模式、忽略大小写等选项
  - 正则表达式解释
- **优先级**: ⭐⭐⭐⭐⭐

#### 3. 时间戳转换器
- **功能**: Unix 时间戳与日期时间互转
- **特性**:
  - 秒级/毫秒级时间戳转换
  - 支持多种日期格式
  - 显示当前时间戳（实时更新）
  - 时区转换
- **优先级**: ⭐⭐⭐⭐

#### 4. 文本差异对比
- **功能**: 对比两段文本的差异
- **特性**:
  - 并排对比视图
  - 高亮显示差异行
  - 支持忽略空格、大小写
  - 导出差异报告
- **优先级**: ⭐⭐⭐⭐

---

### 二、编码/加密工具

#### 5. Base64 编解码
- **功能**: 文本和图片的 Base64 编解码
- **特性**:
  - 文本 ↔ Base64
  - 图片 ↔ Base64 Data URL
  - 支持拖拽图片
  - 批量处理
- **优先级**: ⭐⭐⭐⭐

#### 6. URL 编解码
- **功能**: URL encode/decode
- **特性**:
  - 完整 URL 编解码
  - 组件级编码（encodeURIComponent）
  - 自动识别并解码
- **优先级**: ⭐⭐⭐

#### 7. 哈希计算器
- **功能**: 计算文本和文件的哈希值
- **特性**:
  - 支持 MD5、SHA1、SHA256、SHA512
  - 文本哈希计算
  - 文件哈希计算（支持大文件）
  - 哈希值对比验证
- **优先级**: ⭐⭐⭐⭐

#### 8. UUID/ID 生成器
- **功能**: 生成各种格式的唯一标识符
- **特性**:
  - UUID v1/v4 生成
  - 雪花 ID 生成
  - 批量生成
  - 自定义格式
- **优先级**: ⭐⭐⭐

#### 9. 密码生成器
- **功能**: 生成随机安全密码
- **特性**:
  - 自定义长度
  - 包含/排除字符类型（大小写、数字、特殊字符）
  - 密码强度评估
  - 批量生成
- **优先级**: ⭐⭐⭐

---

## 技术说明

### 窗口类型
- **独立窗口**: 需要较大操作空间的工具（如 JSON 格式化器、文本对比）
- **弹出小窗**: 快速操作的工具（如时间戳转换、取色器）

### 通用特性
- 所有工具支持深色主题
- 支持快捷键操作
- 支持拖拽文件输入
- 结果一键复制
