核心功能

主要能做这些事

📋 四象限任务看板

基于艾森豪威尔矩阵，把任务按重要紧急程度分成四个区域。支持拖拽调整，一眼看清该先做什么。

  • 四象限分类，轻重缓急一目了然
  • AI 智能分类，自动判断优先级
  • 日历视图，月视图周视图切换
  • 悬浮窗模式，随时查看待办

📝 AI 自动日报周报

这是核心功能。AI 读取你今天完成的任务、专注时间，自动生成规范的工作日报。周报同理，一键汇总本周工作。

  • 一键生成，不用手写
  • 自动关联已完成的任务
  • 周报联动日报，自动汇总
  • 格式规范，直接复制发出去

⏱️ 番茄专注时钟

基于番茄工作法的专注计时器。关键是它和任务联动：每次专注的时间会自动记录到对应任务上。

  • 和任务绑定，专注时间自动记录
  • 完成后自动写入日志
  • 可以查看专注统计报表

🚀 应用快速启动

把常用的软件、文件夹、网址收集起来，分类管理。全局快捷键一按，搜索秒开。

  • 分类管理常用应用
  • 全局快捷键搜索
  • 支持文件夹和网址
