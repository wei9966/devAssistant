# 时间解析服务 (TimeParserService) 使用示例

## 功能概述
TimeParserService 支持 20+ 种中文时间表达的自然语言解析，将自然语言转换为标准日期格式。

## 核心接口

### 1. parse_natural_time(text: &str) -> Option<NaiveDate>
解析单个时间表达式，返回日期

### 2. extract_time_expressions(text: &str) -> Vec<TimeExpression>
从文本中提取所有时间表达式

## 支持的时间表达类型

### 1. 相对日期（7种）
- 今天 / 今日
- 明天 / 明日
- 后天
- 大后天
- 昨天 / 昨日
- 前天
- 大前天

示例：
```rust
let date = TimeParserService::parse_natural_time("明天");
// 返回: Some(2025-12-30) (假设今天是 2025-12-29)
```

### 2. 相对周（12种）
- 上上周一、上周一、这周一、本周一、下周一、下下周一
- 支持周一到周日（一、二、三、四、五、六、日/天）

示例：
```rust
let date = TimeParserService::parse_natural_time("下周五");
// 返回: Some(2026-01-03) (假设今天是 2025-12-29，周一)
```

### 3. 相对时间（支持天/周/月/年）
- N天后/前：3天后、一周后、5天前
- N周后/前：两周后、三周前
- N个月后/前：一个月后、半年后、3个月前
- N年后/前：一年后、两年前

示例：
```rust
let date = TimeParserService::parse_natural_time("3天后");
// 返回: Some(2026-01-01) (假设今天是 2025-12-29)

let date = TimeParserService::parse_natural_time("半年后");
// 返回: Some(2026-06-29) (假设今天是 2025-12-29)
```

### 4. 具体日期
- M月D号/日：1月15号、12月31日
- 下/上个月D号：下个月5号、上个月20日

示例：
```rust
let date = TimeParserService::parse_natural_time("1月15号");
// 返回: Some(2026-01-15) (如果当前日期已过1月15号，则返回明年)

let date = TimeParserService::parse_natural_time("下个月5号");
// 返回: Some(2026-01-05) (假设今天是 2025-12-29)
```

### 5. 模糊表达（10种）
- 月初、月底/月末
- 下月初、下个月初
- 下月底、下个月底、下月末、下个月末
- 年初、年底/年末
- 明年初、下年初
- 明年底、明年末、下年底、下年末

示例：
```rust
let date = TimeParserService::parse_natural_time("月底");
// 返回: Some(2025-12-31) (假设今天是 2025-12-29)

let date = TimeParserService::parse_natural_time("年初");
// 返回: Some(2025-01-01) (假设今天是 2025-12-29)
```

### 6. 特殊表达（6种）
- 周末、本周末、这周末
- 下周末
- 下个工作日、下一个工作日
- 上个工作日、上一个工作日

示例：
```rust
let date = TimeParserService::parse_natural_time("周末");
// 返回: Some(2026-01-03) (返回本周六，假设今天是 2025-12-29)

let date = TimeParserService::parse_natural_time("下个工作日");
// 返回: Some(2025-12-30) (假设今天是 2025-12-29，周一)
```

## 中文数字支持

支持中文数字转换：
- 一、二、三...九
- 十、十五、二十、三十一
- 一百、一千
- 万（一万、十万等）

示例：
```rust
let date = TimeParserService::parse_natural_time("三天后");
// 与 "3天后" 效果相同

let date = TimeParserService::parse_natural_time("十五号");
// 解析为15号
```

## 提取多个时间表达

从文本中提取所有时间表达：

```rust
let text = "记得明天下午3点开会，后天要提交报告，下周五进行评审";
let expressions = TimeParserService::extract_time_expressions(text);

// 返回:
// [
//   TimeExpression {
//     original: "明天",
//     parsed_date: 2025-12-30,
//     confidence: 0.99
//   },
//   TimeExpression {
//     original: "后天",
//     parsed_date: 2025-12-31,
//     confidence: 0.99
//   },
//   TimeExpression {
//     original: "下周五",
//     parsed_date: 2026-01-03,
//     confidence: 0.90
//   }
// ]
```

## 置信度说明

TimeExpression 包含置信度字段 (0-1)：
- 0.99: 明确的相对日期（今天、明天）
- 0.95: 包含数字的表达
- 0.90: 周相关表达
- 0.85: 月/年相关表达
- 0.80: 其他表达

## 实际应用场景

### 1. 智能待办事项
```rust
// 用户输入: "明天提交代码，下周五进行代码评审"
let text = "明天提交代码，下周五进行代码评审";
let expressions = TimeParserService::extract_time_expressions(text);

for expr in expressions {
    println!("任务截止日期: {}, 置信度: {}", expr.parsed_date, expr.confidence);
}
```

### 2. 智能提醒
```rust
// 用户输入: "3天后提醒我续费"
if let Some(date) = TimeParserService::parse_natural_time("3天后") {
    // 设置提醒时间为 date
    println!("提醒时间设置为: {}", date);
}
```

### 3. 日程安排
```rust
// 用户输入: "下个月5号安排会议"
if let Some(date) = TimeParserService::parse_natural_time("下个月5号") {
    // 在日历中创建会议
    println!("会议日期: {}", date);
}
```

## 技术实现

### 解析流程
1. 使用正则表达式匹配时间模式
2. 通过规则引擎计算日期
3. 返回标准 NaiveDate 格式
4. 提供置信度评分

### 关键特性
- 支持中文数字和阿拉伯数字混用
- 智能处理月份天数（如2月28/29天）
- 自动处理闰年
- 支持过去和未来的日期
- 准确计算周偏移

## 注意事项

1. 所有解析基于当前系统时间 (Local::now())
2. 具体日期（如"1月15号"）如果已过，会自动返回明年的日期
3. 周末默认返回周六
4. 工作日自动排除周六日
5. 月底/月末会根据实际月份天数计算

## 总结

TimeParserService 提供了强大的中文时间表达解析能力，支持：
- ✅ 20+ 种时间表达方式
- ✅ 中文数字智能识别
- ✅ 多时间表达提取
- ✅ 置信度评分
- ✅ 标准日期格式输出
- ✅ 完整的单元测试覆盖

适用于待办事项、日程管理、智能提醒等场景。
