## 测试步骤

### 手动测试

1. 启动应用
2. 打开 AI 对话界面
3. 依次输入测试用例
4. 观察 AI 响应
5. 检查数据库 `context_memory` 表
6. 验证后续对话是否利用了保存的偏好

### 查看数据库记录

```sql
-- 查看所有保存的偏好
SELECT * FROM context_memory
WHERE context_type = 'preference'
ORDER BY importance DESC, created_at DESC;

-- 查看特定类型的偏好
SELECT * FROM context_memory
WHERE context_key = 'time_preference';

-- 查看项目关联
SELECT * FROM context_memory
WHERE context_type = 'entity' AND context_key LIKE 'task_project_%';
```

### 日志检查

启动应用时设置环境变量：
```bash
RUST_LOG=info cargo run
```

查找日志中的关键信息：
```
[Context Memory] 提取到时间偏好: 下午 (重要性: 8)
[Context Memory] 提取到工作模式偏好: 番茄钟 (时长: Some(25), 重要性: 7)
[AI Chat] 💾 保存上下文记忆: time_preference (type=preference, importance=8)
```

## 调试技巧

### 启用详细日志
```rust
log::debug!("[Implicit Prefs] Checking message: {}", user_message);
log::debug!("[Implicit Prefs] Pattern matched: {:?}", caps);
```

### 打印中间结果
```rust
println!("Extracted preferences: {:?}", preferences);
```

### 单独测试正则表达式
```rust
#[test]
fn test_regex_patterns() {
    let pattern = Regex::new(r"我(一般|习惯|通常|喜欢).{0,15}(早上|上午|中午|下午|晚上|深夜)").unwrap();
    assert!(pattern.is_match("我一般下午效率高"));
}
```
