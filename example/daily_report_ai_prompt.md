# AI 日报生成提示词模板使用说明

## 功能概述

该功能通过专业的 AI 提示词模板，让 AI 基于真实数据生成有洞察力的工作日报，而不是简单的硬编码模板。

## 核心特性

### 1. 数据驱动
- 基于真实的任务完成数据
- 包含专注时长和番茄钟统计
- 对比昨日数据，分析趋势变化

### 2. 智能分析
AI 会根据数据生成三个部分：
- **今日工作总结**：总结工作重点和成果
- **效率分析**：对比昨日数据，分析效率变化
- **明日建议**：给出具体可执行的改进建议

### 3. 人性化语气
- 像工作伙伴一样友好亲切
- 给予鼓励和支持，不责备
- 使用适当的 emoji 让内容生动

## 技术实现

### 1. 提示词模板函数

位置：`src-tauri/src/services/ai_chat_service.rs`

```rust
fn build_daily_report_prompt(
    date: &str,
    completed_tasks: &[(String, i32)],
    focus_minutes: i32,
    pomodoro_count: i32,
    yesterday_task_count: i32,
    yesterday_focus_minutes: i32,
) -> String
```

### 2. 数据查询

在 `generate_daily_report` 函数中：
- 查询当日完成的任务列表（标题 + 优先级）
- 查询当日专注时长和番茄钟数量
- 查询昨日完成任务数量和专注时长（用于对比）

### 3. AI 调用流程

1. 用户说"生成日报"
2. AI 识别意图，调用 `generate_daily_report` 函数
3. 查询今日和昨日数据
4. 使用 `build_daily_report_prompt` 构建提示词
5. 返回 `need_ai_generation` 响应类型
6. 主流程检测到该类型，调用 AI 生成日报
7. 保存到工作日志

## 提示词设计原则

### 核心要求
1. **禁止编造** - 必须基于真实数据，严禁虚构
2. **如实说明** - 数据不足时坦诚说明，不假设
3. **友好语气** - 像朋友一样鼓励，不是冷冰冰的机器
4. **具体分析** - 避免空泛套话，给出具体洞察

### 数据对比
提供了今日和昨日的对比数据：
- 任务完成数变化
- 专注时长变化
- 用于分析效率趋势

### 写作风格
- 用"你"称呼用户，拉近距离
- 适当使用 emoji（但不过度）
- 数据准确但表达人性化
- 每句话都有价值，不重复

## 使用示例

### 场景 1：高效工作日
```
今日数据：
- 完成任务: 6 个
- 专注时长: 4 小时 30 分钟
- 番茄钟: 9 个

昨日数据：
- 完成任务: 3 个
- 专注时长: 2 小时 15 分钟
```

AI 会分析：
- 效率大幅提升
- 重点提及完成的高优先级任务
- 鼓励保持这种状态
- 建议继续使用番茄钟

### 场景 2：低效工作日
```
今日数据：
- 完成任务: 1 个
- 专注时长: 45 分钟
- 番茄钟: 2 个

昨日数据：
- 完成任务: 4 个
- 专注时长: 3 小时
```

AI 会：
- 以关心的语气提醒效率下降
- 不责备，而是温和建议
- 分析可能的原因（如任务难度、时间管理）
- 给出具体改进方向

### 场景 3：休息日
```
今日数据：
- 完成任务: 0 个
- 专注时长: 0 分钟
- 番茄钟: 0 个
```

AI 会：
- 识别为休息或规划日
- 不强调"没完成任务"
- 建议好好休息，为明天准备

## 关键优势

### 相比硬编码模板
1. **动态分析** - 根据实际数据变化给出不同建议
2. **个性化** - 每份日报都是独特的，不会千篇一律
3. **有洞察** - 能发现数据中的趋势和异常
4. **有温度** - 语气自然，像真人一样关心用户

### 数据真实性保证
- 提示词中明确禁止编造信息
- 要求如实说明数据不足的情况
- AI 只能基于提供的数据进行分析
- 避免假设用户的工作内容或心理状态

## 扩展性

该模板设计可以轻松扩展到其他报表生成场景：
- 周报生成
- 月报生成
- 项目总结
- 效率分析报告

只需要调整：
1. 数据查询范围
2. 提示词中的时间维度
3. 分析维度和建议方向
